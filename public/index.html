🏷️ Microservicio de Promociones

Servicio REST de solo lectura con paginación, filtros deterministas de vigencia y consultas por categoría o producto sobre MongoDB Atlas.

Verificando conexión con el servicio...
📖
Solo Lectura
Expone exclusivamente GET /health, GET /items y GET /items/:id.
🔢
Orden y Paginación
Ordenado por id ascendente con parámetros limit (1-100) y offset (≥ 0).
🔍
Filtros AND & Textos
Combina filtros con AND. Coincidencia exacta sin distinguir mayúsculas ni minúsculas.
🛡️
Respuestas de Error
Formato estándar { "error": "...", "message": "..." } con 400 y 404.

📚 Especificación de Rutas y Parámetros

Método y Ruta Parámetros Query Descripción y Reglas
GET /health Ninguno Verifica que el servicio y la base de datos MongoDB Atlas estén operativos. Responde 200 con { status: "ok", collection: "promociones" }.
GET /items categoriaId (^CAT[0-9]+$)
productoId (^PRD[0-9]+$)
vigente (true | false)
fecha (YYYY-MM-DD)
limit (1-100, default 20)
offset (≥ 0, default 0) 		Devuelve la lista paginada y ordenada por id ascendente. El campo total representa la cantidad total sin paginación. Parámetros fuera de rango o tipo devuelven HTTP 400.
GET /items/:id id (path, ej. PRM001) Detalle de la promoción. Devuelve 200 con el schema Item o 404 si el ID no existe en la base de datos.
GET /openapi.yaml Ninguno Descarga la especificación formal OpenAPI 3.0.3 completa del microservicio.
